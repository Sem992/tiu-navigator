# ТИУ НАВИГАТОР

Сайт-помощник для студентов Тюменского индустриального университета (Streamlit).

## Запуск локально
    pip install -r requirements.txt
    streamlit run app.py

## Структура
- `app.py` — интерфейс (главная, разделы, база вопросов, карта, раздел для иностранных студентов).
- `kb.py` — логика базы знаний: загрузка, поиск (рус/англ), фильтры, статусы. Не зависит от Streamlit.
- `data/knowledge_base_new.json` — первая партия, 200 карточек из Excel.
- `data/knowledge_base_257.json` — вторая партия, 257 карточек (первые 100 — раздел «Что делать, если…»).
- `data/foreign_students.py` — контент раздела для иностранных студентов (RU/EN).
- `tools/import_excel.py` — перезагрузка базы из Excel: `python tools/import_excel.py файл.xlsx` (нужен openpyxl). Лист «200 карточек» -> первая партия, лист «Карточки» -> вторая.
- `tests/test_kb.py` — тесты: `python -m unittest discover -s tests`.

## Обновление базы вопросов
Положите Excel с листом «Карточки» (14 колонок: №, Вопрос, Категория, Ответ, Куда идти, Адрес, Кабинет, Телефон, Email, Документы, Срок, Официальный источник, Статус, Раздел) и запустите `tools/import_excel.py`.
Старые вопросы (`QUESTIONS_DATA` в `app.py` и первая партия) не затрагиваются; дословные дубли пропускаются, похожие вопросы перечисляются в отчёте импорта.

## Пустые и неподтверждённые поля
Сайт показывает только заполненные поля карточки. Пустые значения, «уточняется», «не подтверждено», «требует уточнения», «не опубликован» и подобные пометки не выводятся: их убирают `kb.clean_field` (поля) и `kb.clean_answer` (фразы «… не найдено» в тексте ответа). Статус из Excel хранится в данных (`lastChecked`), но на сайте как предупреждение не показывается.
