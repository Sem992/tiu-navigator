# ТИУ НАВИГАТОР

Сайт-помощник для студентов Тюменского индустриального университета (Streamlit).

## Запуск локально
    pip install -r requirements.txt
    streamlit run app.py

## Структура
- `app.py` — интерфейс (главная, разделы, база вопросов, карта, раздел для иностранных студентов).
- `kb.py` — логика базы знаний: загрузка, поиск (рус/англ), фильтры, статусы. Не зависит от Streamlit.
- `data/knowledge_base_new.json` — 200 карточек из Excel.
- `data/foreign_students.py` — контент раздела для иностранных студентов (RU/EN).
- `tools/import_excel.py` — перезагрузка базы из Excel: `python tools/import_excel.py файл.xlsx` (нужен openpyxl).
- `tests/test_kb.py` — тесты: `python -m unittest discover -s tests`.

## Обновление базы вопросов
Обновите Excel (лист «200 карточек», те же 13 колонок) и запустите `tools/import_excel.py`.
Старые 43 вопроса лежат в `app.py` (`QUESTIONS_DATA`) и не затрагиваются; дубли пропускаются.

## Важно перед публикацией
198 из 200 новых карточек имеют статус «Требует уточнения»: сайт показывает эту пометку пользователю.
Миграционные сроки и перечни документов не заполнены намеренно — их подтверждает ТИУ.
